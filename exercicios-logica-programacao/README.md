# Exercícios de Lógica de Programação

Exercícios feitos durante a matéria de lógica de programação do curso de
Análise e Desenvolvimento de Sistemas (Cotemig).

## Programas

- **calculadora.py** - calculadora com soma, subtração, multiplicação,
  divisão, potência e raiz quadrada
- **jogo_da_forca.py** - jogo da forca no terminal, com palavra sorteada
- **conversor_unidades.py** - converte km/m/cm, kg/g e Celsius/Fahrenheit

## Como rodar

```
python3 calculadora.py
python3 jogo_da_forca.py
python3 conversor_unidades.py
```
