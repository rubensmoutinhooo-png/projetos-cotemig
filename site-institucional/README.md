# Site Institucional — Doce Aroma (Padaria e Confeitaria)

Site institucional estático, responsivo, feito em HTML, CSS e JavaScript puro,
para uma padaria/confeitaria fictícia usada como estudo de caso.

Projeto de prática desenvolvido a partir do conteúdo de desenvolvimento web
(HTML, CSS e JavaScript) do curso de Análise e Desenvolvimento de Sistemas
(Cotemig).

## Páginas

- **index.html** — página inicial, com destaque dos produtos e chamada para contato
- **sobre.html** — história da empresa e valores
- **servicos.html** — catálogo de produtos oferecidos
- **contato.html** — formulário de contato com validação em JavaScript

## Funcionalidades

- Layout responsivo (menu hambúrguer em telas pequenas)
- Navegação com destaque automático da página atual
- Formulário de contato com validação de campos e de formato de e-mail
- Estilização consistente entre as páginas via CSS compartilhado

## Tecnologias

- HTML5
- CSS3 (Flexbox e Grid, variáveis CSS)
- JavaScript (sem frameworks ou bibliotecas)

## Como executar

Basta abrir o arquivo `index.html` em qualquer navegador — não há necessidade
de servidor ou instalação de dependências.

