# Projetos Cotemig

Pasta com os trabalhos feitos durante o curso tecnico de Informatica no Cotemig (Belo Horizonte), com especializacao em desenvolvimento mobile (iOS/Android), reorganizados aqui pra guardar no GitHub.

#### Projetos

1. [agenda-de-contatos](./agenda-de-contatos) — sistema de cadastro de contatos (CRUD) em Python + SQLite<br>
2. [controle-de-estoque](./controle-de-estoque) — controle de estoque e vendas em Python + SQLite<br>
3. [site-institucional](./site-institucional) — site institucional (HTML, CSS e JavaScript)<br>
4. [exercicios-logica-programacao](./exercicios-logica-programacao) — calculadora, jogo da forca e conversor de unidades em Python<br>
5. [banco-de-dados-biblioteca](./banco-de-dados-biblioteca) — modelagem de banco de dados de uma biblioteca (SQL)<br>
6. [analise-de-dados](./analise-de-dados) — analise de notas de alunos com pandas e matplotlib

Cada pasta tem seu proprio README explicando o que o projeto faz e como rodar.
