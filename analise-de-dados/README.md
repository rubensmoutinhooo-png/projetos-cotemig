# Análise de Dados - Notas dos Alunos

Trabalho de análise de dados feito durante o curso de Análise e
Desenvolvimento de Sistemas (Cotemig). Le um CSV com notas de alunos e
calcula estatísticas simples (média, maior nota, menor nota, média por
matéria e por aluno) e gera um gráfico.

## Arquivos

- `notas_alunos.csv` - dados de exemplo (aluno, matéria, nota)
- `analise_notas.py` - código que lê o CSV e faz a análise
- `media_por_materia.png` - gráfico gerado (média de notas por matéria)

## Bibliotecas usadas

- pandas
- matplotlib

## Como rodar

```
pip install pandas matplotlib
python3 analise_notas.py
```
