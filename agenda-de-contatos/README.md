# Agenda de Contatos

Trabalho de lógica de programação e banco de dados feito durante o curso de
Análise e Desenvolvimento de Sistemas (Cotemig). Sistema simples de agenda de
contatos rodando no terminal, com Python + SQLite.

## O que faz

- Cadastra contato (nome, telefone, email, categoria)
- Lista os contatos
- Busca contato pelo nome
- Edita um contato
- Apaga um contato

## Como rodar

```
python3 agenda.py
```

Precisa ter o Python instalado. O banco (`contatos.db`) é criado sozinho na
primeira vez que roda.

## Arquivos

- `agenda.py` - todo o código
- `contatos.db` - banco de dados (gerado ao rodar)
